# Autonomys

> Autonomys is a decentralized infrastructure network providing permanent, verifiable, content-addressed data storage and AI-ready blockchain services, secured by Proof-of-Archival-Storage consensus. Its developer surface centers on Auto Drive (permanent storage with a REST API) and the Auto SDK (a TypeScript toolkit), alongside Auto EVM, Auto Agents, and Auto ID.

This file was generated by the API Evangelist enrichment pipeline from the Autonomys public developer surface and the artifacts captured in this repository.

## APIs

- [Auto Drive API](https://develop.autonomys.xyz/sdk/auto-drive/api_reference): REST API for permanent, content-addressed (CID) storage — uploads, objects, downloads, subscriptions, and on-chain storage-credit intents. Base URL https://mainnet.auto-drive.autonomys.xyz
- [Interactive API docs](https://mainnet.auto-drive.autonomys.xyz/api/docs): Stoplight Elements reference for Auto Drive.
